# DormFinder

**A Web-Based Dormitory Search and Management System**

DormFinder is a web-based platform designed to help students find dormitories, boarding houses, and apartments in Minglanilla, Cebu.

The system allows students to explore available accommodations, compare property details, check room availability, view property locations, communicate with property owners, and submit booking requests.

## Main Objectives

- Make accommodation searching easier for students.
- Provide accessible property and room information.
- Help students discover accommodations based on their preferences.
- Provide property owners with tools to manage their listings and booking requests.

## Core Functionalities

### Student / Boarder
- User registration and login
- Browse accommodation listings
- Search and filter properties
- View property details, prices, and amenities
- Check room availability
- View property locations through an interactive map
- Send messages to property owners
- Submit booking requests
- Manage booking information

### Property Owner
- Owner registration and login
- Add accommodation listings
- Edit and manage property information
- Manage room availability
- View and respond to booking requests
- Communicate with students

### Administrator
- Administrator login
- Manage user accounts
- Manage accommodation listings
- Monitor system information

## Installation and Setup

1. Clone or download the project repository.
2. Open the project folder in your code editor.
3. Create and activate your Python virtual environment.
4. Install the required dependencies.

```bash
pip install -r requirements.txt
```

5. Configure the required environment variables, if applicable.
6. Initialize the database if necessary.
7. Start the Flask application.

```bash
python main.py
```

8. Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## Project Scope and Limitations

DormFinder provides accommodation information and booking request management. It does not process online payments, deposits, or rental agreements. Final rental arrangements are handled directly between students and property owners.

The system also does not independently guarantee the legitimacy of property owners or listings.
